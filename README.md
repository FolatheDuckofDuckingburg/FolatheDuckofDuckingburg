## 🔬 CURRENT RESEARCH

### 🧠 bigP3BCI Analysis

**Trial-level feedback timing × BCI selection accuracy**

I'm extracting trial-level **(L, Y)** data from a public **P300 BCI dataset on PhysioNet** to test whether feedback timing predicts selection accuracy.

**Current progress**

* 🧩 Reverse-engineered channel encodings for **Study M**
* 🎯 `SelectedTarget` decoded as a cell index: `(row − 1) × 8 + col`
* 🎯 `CurrentTarget` represents the actual target
* 📊 **30 trials** extracted from one subject
* 🔁 Scaling the analysis to additional subjects

**Goal:** turn the timing hypothesis into a directly testable, trial-level analysis.

### ⚡ Neural Feedback Optimization Theory — NFOT

A **falsifiable hypothesis** about feedback timing in closed-loop systems.

NFOT investigates whether the timing of information returning to a system is systematically related to subsequent performance.

🧪 **Status:** preregistered test protocol
