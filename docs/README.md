# Research portfolio site

This folder contains the static portfolio website for Folarera Ayobami Kassim.

## Publish with GitHub Pages

1. Open the repository: https://github.com/FolatheDuckofDuckingburg/FolatheDuckofDuckingburg
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/docs**, then save.
5. Wait for GitHub Pages to finish its first deployment.

The site will be available at:

https://folatheduckofduckingburg.github.io/FolatheDuckofDuckingburg/

## Edit the site

- Homepage content and styling are in `index.html`.
- The page is intentionally self-contained: no build step, framework, paid API, external font, or generated imagery is required.
- Update project descriptions and links as projects evolve. Keep research claims limited to results that have actually been verified.

## Design notes

Dark navy research-editorial theme, responsive layout, semantic HTML, accessible navigation, reduced-motion support, and no third-party runtime dependencies.
